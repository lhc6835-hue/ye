# Glass Fruit

하얀 스튜디오의 나무 도마 위에 놓인 유리 과일을 칼로 자르는 3D 게임이에요.

화면에는 **자른 과일 수**와 **설정 버튼**만 있어요.

## 조작

| 기기 | 방법 |
|---|---|
| 컴퓨터 | 마우스를 움직이면 칼이 커서를 따라와요. 과일 위에서 아래로 내리면 내리찍어 자르고, 옆으로 그으면 눕혀서 썰어요. 소리는 화면을 한 번 클릭하면 켜져요(브라우저 정책). |
| 폰 | 손가락으로 화면을 짚고 그어요. 칼은 손가락보다 살짝 위에 나타나서 손에 가려지지 않아요. 손을 떼면 칼이 비켜나요. |

칼날 방향은 움직이는 방향을 따라가요. 날이 앞장서야 잘리고, 칼등이나 옆면으로 밀면 과일이 밀려나요.

## 자르는 느낌

1. **걸림**: 날이 유리에 닿으면 바로 들어가지 않고 표면에서 멈춰요. 커서가 칼보다 앞서 나가면서 힘이 쌓이고, 과일이 눌리면서 칼이 미세하게 떨려요.
2. **파고듦**: 힘이 과일 크기와 단단함에 맞는 값을 넘으면 '빠각' 소리와 함께 날이 박혀요.
3. **저항 속 미끄러짐**: 그 뒤로는 부드럽게 내려가요. 날에 걸린 유리 폭(그 깊이의 단면 길이)이 넓을수록 느려지고, 2~4 mm마다 미세한 걸림이 바삭거리는 소리와 맞춰 들어가요.
4. **갈라짐**: 날이 지나간 곳까지만 단면이 드러나고, 날 두께 때문에 두 조각이 조금씩 벌어져요.
5. **분리**: 반대편으로 빠져나오면 두 조각이 각자의 강체가 돼서 실제 물리로 쓰러지고 굴러요.

잘린 조각은 갈라져 기우는 모습만 0.7초 보여주고, 도마 위에서 굴러다니며 달그락거리지 않도록 0.45초 동안 소리 없이 작아져 사라져요. 부딪히는 소리는 물체마다 처음 닿을 때 한 번만 "툭" 하고 나요. 과일을 자르면 숫자가 올라가고 1초 뒤 새 과일이 떨어져요.

## 과일 13종

사과, 배, 오렌지, 레몬, 라임, 키위, 딸기, 복숭아, 자두, 망고, 수박, 바나나, 용과. 설정에서 나올 과일을 고를 수 있어요.

자른 면에는 그 과일의 속이 보여요. 사과의 씨방과 씨, 귤류의 과육 칸과 속껍질, 키위의 씨 고리와 심, 수박 씨와 껍질층, 복숭아·자두·망고의 씨, 용과의 검은 씨가 있어요. 어느 각도로 잘라도 그 단면에 맞는 모양이 나와요.

## 기술

- **렌더링**: Three.js `MeshPhysicalMaterial`로 그린 진짜 투과 유리예요(굴절률 1.5, 분산, 두께에 따른 색 감쇠). 스튜디오 HDRI 반사, PCF 소프트 그림자, 반투명 유리 그림자, 그림자 안에 맺히는 집광(커스틱), Neutral 톤매핑을 쓰고 배경은 순백색이에요.
- **자르기**: `src/slicer.js`가 닫힌 삼각형 메시를 평면으로 잘라 두 개의 닫힌 메시를 만들고 단면을 삼각분할해요(구멍 있는 단면 포함). 모든 조각이 원래 과일의 좌표계를 유지해서, 단면 셰이더가 오브젝트 좌표로 과육·씨·껍질층을 그려요. 껍질 깊이는 과일 윤곽에서 미리 구운 거리장(SDF) 텍스처로 계산해요.
- **물리**: Rapier3D 강체예요. 유리 밀도 2500 kg/m³, 조각마다 볼록 껍질 충돌체, 마찰·반발·CCD를 써요. 충돌 세기와 상대 표면(도마, 탁자, 유리)에 따라 효과음이 달라져요.
- **칼**: 2.2 mm 척추에서 칼날까지 플랫 그라인드로 깎인 실제 단면에, 배(belly) 곡선, 이방성 브러시드 스틸, 볼스터, 나무 손잡이와 리벳 3개를 붙였어요. 부스러기만 밀어내는 키네마틱 충돌체도 있어요.
- **소리**: 진짜 유리 덩어리를 부드럽게 써는 느낌을 목표로 했어요. 유리 울림("팅", "쨍")은 아예 없어요. 칼이 움직이는 동안은 긁는 소리 녹음을 겹친 그레인으로 이어 붙인 "스윽" 질감이 흐르고, 칼 속도와 단면 폭에 따라 크기와 밝기가 바뀌어요. 가끔 낮고 따뜻한 바삭 알갱이가 섞여요. 칼이 걸릴 땐 다진 눈을 누르는 듯한 "슥", 도마에는 둔탁한 나무 "툭" 소리가 나요. 모든 소리는 고역을 깎았고, 짧고 어두운 룸 리버브와 리미터를 거쳐요. 출처는 `assets/CREDITS.md`에 있어요. `tools/audio-demo.js`로 소리만 시험 녹음해 볼 수 있어요.
- **품질**: 자동, 낮음, 보통, 높음. 자동은 폰에서 보통, 컴퓨터에서 높음으로 시작하고, 프레임이 계속 느리면 한 단계씩 내려가요.

## 실행

ES 모듈과 npm 패키지를 쓰기 때문에 빌드해서 띄워요.

```bash
cd glass
npm install
npm run build          # dist/index.html + dist/assets
cd dist && python3 -m http.server 8000
```

그다음 `http://localhost:8000` 접속.

테스트(모든 과일을 무작위로 여러 번 잘라도 조각이 닫힌 메시로 남고 부피가 보존되는지 확인):

```bash
npm test
```

디버그용으로 `?gallery=whole`, `?gallery=cut`, `?gallery=cut2`를 붙이면 13종을 통째로 또는 잘라서 한눈에 보여줘요.

배포: 저장소의 Pages 워크플로가 이 폴더도 빌드해서 `https://lhc6835-hue.github.io/ye/glass/`에 올려요(`main` 브랜치에 푸시될 때).

## 구조

- `src/main.js` 시작, 입력(마우스/터치), 프레임 루프, 자동 품질
- `src/stage.js` 렌더러, 카메라 맞춤(가로/세로), 조명, HDRI, 도마, 흰 탁자
- `src/fruits.js` 과일 13종의 모양, 껍질 색, 유리 재질, 단면 셰이더, 꼭지·잎
- `src/glsl.js` 노이즈, 셀 노이즈, 범프 공용 GLSL
- `src/slicer.js` 메시 절단과 단면 생성
- `src/game.js` 칼 조작, 자르기 상태 기계, 조각, 생성/정리, 커스틱
- `src/knife.js` 칼 모델
- `src/physics.js` Rapier 월드, 충돌 그룹, 충돌 감지
- `src/audio.js` 효과음 엔진
- `src/ui.js` 숫자와 설정 시트
