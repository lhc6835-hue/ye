처음 한 번만 GitHub 토큰을 넣고 비밀번호를 정하면, 다음부터는 비밀번호만 입력하면 돼요. 토큰은 이 비밀번호로 암호화돼서 저장소에 저장되고, 비밀번호 자체는 어디에도 저장되지 않아요.

      

        
        
        
      

      
      

        
        
      

      암호화된 토큰은 공개 저장소에 올라가요. 길고 다른 데서 안 쓰는 비밀번호일수록 안전해요 (예: 짧은 문장).
      

        
        
      

      

      

        토큰 만드는 법 (1분)
        
    
          
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. 
          
  2. Repository access: Only select repositories → 이 사이트 저장소 하나만 선택
    3. 
          
  3. Permissions → Repository permissions → Contents: Read and write (나머지는 건드리지 않기)
    4. 
          
  4. 만료일을 정하고 생성. 토큰이 만료되면 여기서 새 토큰으로 다시 설정하면 돼요
    5.
